# =======================================================================
# Guía de Despliegue en Render - Django + React
# =======================================================================
# NOTAS IMPORTANTES ANTES DE EMPEZAR
# =======================================================================
# Esta guía纪录a los pasos correctos para desplegar el proyecto en Render,
# incluyendo todas las correcciones necesarias para evitar errores comuns.
#
# Arquitectura del proyecto:
# - Backend: Django (Python) en carpeta /backend
# - Frontend: React (Vite) en carpeta /frontend
#
# URLs resultantes (ejemplo):
# - Backend: https://gestion-saude-backend.onrender.com
# - Frontend: https://mis-proyectos-1-thyh.onrender.com
#
# =======================================================================
# PASOS PARA DESPLEGAR EL BACKEND
# ========================================================================
# 1. En Render Dashboard: New → Web Service
# 2. Configurar:
#    - Root Directory: backend
#    - Environment: Python
#    - Build Command: pip install -r requirements.txt && python manage.py migrate
#    - Start Command: gunicorn core.wsgi:application --bind :3000
#    - Plan: Free
# 3. Agregar Environment Variables:
#    - KEY: SECRET_KEY_BASE | VALUE: (generar con openssl rand -base64 32)
#    - KEY: DEBUG | VALUE: False
# 4. Deploy: Manual Deploy → Deploy latest commit
#
# IMPORTANTE: El Start Command debe incluir --bind :3000 (NO usar $PORT)
#
# =======================================================================
# PASOS PARA DESPLEGAR EL FRONTEND
# ========================================================================
# 1. En Render Dashboard: New → Web Service (NO Static Site)
# 2. Configurar:
#    - Root Directory: frontend
#    - Environment: Node
#    - Build Command: npm install && npm run build
#    - Start Command: npx serve -s dist -l 3000
#    - Plan: Free
# 3. Agregar Environment Variable:
#    - KEY: VITE_API_URL | VALUE: https://gestion-saude-backend.onrender.com/api/
# 4. Deploy: Manual Deploy → Deploy latest commit
#
# IMPORTANTE: 
# - Usar Web Service (no Static Site) para que funcione el refresh
# - El flag -s en serve hace que maneje SPA correctamente
# - La URL debe terminar en /api/ (con barra)
# Dominios actuales:
# - Frontend: https://gestion-saude.onrender.com
# - Backend: https://gestion-saude-backend.onrender.com
#

# =======================================================================
# PROBLEMAS COMUNES Y SOLUCIONES
# ========================================================================
#
# Error: "Cannot find manage.py"
# → Solución: Cambiar Root Directory de vacío a "backend"
#
# Error: "timeout of 30000ms exceeded" en login
# → El backend está caído o mal configurado
# → Verificar que Start Command tenga --bind :3000
# → Verificar que el backend esté activo (no suspended)
#
# Error: "No open HTTP ports detected"
# → El binding es incorrecto. Usar: gunicorn core.wsgi:application --bind :3000
#
# Error: CORS policy - No 'Access-Control-Allow-Origin'
# → Agregar el dominio del frontend a CORS_ALLOWED_ORIGINS en settings.py
# → Ejemplo: "https://mis-proyectos-1-thyh.onrender.com"
#
# Error: Imágenes no cargan
# → Verificar que MEDIA_URL esté configurado en settings.py
# → Verificar queurls.py sirva archivos estáticos em produção:
#   urlpatterns += static(settings.MEDIA_URL, document_root=settings.MEDIA_ROOT)
#
# Error: 401 Unauthorized
# → El frontend está usando URL incorrecta
# → Verificar VITE_API_URL termina em /api/
#
# Error: Blank page em frontend
# → Verificar que VITE_API_URL está configurado corretamente
# → Hacer deploy novamente tras agregar la variable
#
# Error: "Not Found" al hacer refresh (excepto en homepage)
# → El frontend está configurado como Static Site
# → Cambiar a Web Service y usar: npx serve -s dist -l 3000
#
